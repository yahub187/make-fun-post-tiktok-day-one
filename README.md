This entry hands in the TikTok video https://www.tiktok.com/@guakbu/video/7711531701008207124 for make.fun's "Day one, day seven" bounty: the same tiny agent-built game on the day it was made and after a week of daily updates, closing with make.fun's referral end card. The program itself is deliberately small — main.ts copies VIDEO.json into the output directory, where the gate reads the video's address — because the video is the real entry: places go by its views plus ten times its likes, comments, shares and saves.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
